# 产品制造经营分析作品介绍

> 主要分为：质量运营总览、质量异常追溯、供应商异常绩效、销售数据、物流运输、客户投诉七个模块

## 一、项目简介

项目模拟了生产制造的部分主要模块数据，基于三年的质量管理经验，利用Python、MySQL、PowerBI技术栈模拟前期企业连接导入ERP平台前将Excel手工账进行清洗、导出、分发部门，再用数据库建立对应事实表、维度表及数据的约束避免后期使用系统时数据录入再产生脏数据，最终在BI中构建对应星型模型、DAX业务层面函数展示可持续自动更新的交互性报表供管理层进行企业经营管理分析。

此项目所有的业务数据均为模拟生成的数据，仅用于面试作品展示，与任何真实企业都无关联。

## 二、业务流程
为控制作品的制作周期 精简了一些业务流程 主要为展示多维度的分析能力。
```text
供应商来料
    ↓
IQC检验
    ↓
仓库收货盘点管理
    ↓
客户订单销售分析
    ↓
物流运输
    ↓
客户签收
    ↓
客户投诉、根本原因分析与关闭
```


## 三、技术栈工具分工

```text
模拟从各部门接受的Excel原始台账
      ↓
Python / Pandas
数据清洗、格式统一、异常识别、质量校验（此处仅以质量模块为例进行了清洗）
      ↓
MySQL
事实表与维度表、主外键约束、完整性检查、SQL分析（指标演算仅以质量模块为例）
      ↓
Power BI
建立星型模型、DAX指标、筛选上下文、质量钻取追溯，最终呈现可视化作品
```

| 工具 | 承担责任                 | 使用具体方法         |
|---|----------------------|----------------|
| Python / Pandas | 处理原始Excel当中的脏数据      | 日期与数值转换、空值处理、去重、异常输出、业务规则校验 |
| MySQL | 将清洁数据保存并确定主外键        | 建表、主外键、CHECK约束、导入校验、聚合查询、窗口函数 |
| Power BI | 将数据提取并建构模型，最终呈现可视化作品 | 星型模型、DAX、钻取、书签 |



## 四、数据模型介绍

共享维度、多事实主题的星型模型。维度表单向筛选事实表。

### 维度表

| 表名 | 粒度 | 主要用途 |
|---|---|---|
| `dim_date` | 一行一天 | 年、季度、月份及时间智能分析 |
| `dim_product` | 一行一个零件 | 产品名称、类别和规格分析 |
| `dim_supplier` | 一行一个供应商 | 供应商等级、地区及质量绩效分析 |
| `dim_customer` | 一行一个客户 | 客户等级、行业和区域分析 |
| `dim_warehouse` | 一行一个仓库 | 仓库及区域库存分析 |
| `dim_carrier` | 一行一个承运商 | 承运商类型、服务等级和运输表现分析 |

### 事实表

| 表名 | 粒度                | 业务主题               |
|---|-------------------|--------------------|
| `fact_iqc` | 一行一批IQC检验来料       | 首检、复检、检验数量和不合格数量   |
| `fact_defect` | 一行一个批次中的一种不合格     | 一批次产品中分别计算不合格类别数量  |
| `fact_sales_order` | 一行代表客户订单的一条产品明细   | 销售额、成本、毛利润和订单分析    |
| `fact_inventory_snapshot` | 一行代表月末某仓库某产品的库存状态 | 库存金额、可用量、安全库存和呆滞风险 |
| `fact_shipment` | 一行代表一条订单明细的一次发货   | 时效、承运商表现和运输费用      |
| `fact_customer_complaint` | 一行代表一条客户投诉        | 投诉类型、责任方、损失金额      |

其中库存事实表设计时按照快照表做的，所以库存余额不能跨月份累加。

## 五、Power BI报表页面简介

| 页面 | 主要回答的问题 | 主要功能                   |
|---|---|------------------------|
| 来料质量运营总览 | 当前IQC质量水平如何，哪个月份或供应商出现异常 | FPY、同比环比、月度趋势、较差的供应商   |
| 来料质量异常追溯 | 异常月份由哪些产品和供应商造成 | 年月钻取、产品与供应商上下文联动       |
| 供应商质量绩效分析 | 供应商是否达到等级目标，问题是否长期存在 | 目标线、月度FPY、复检率、缺陷结构     |
| 销售经营与客户价值分析 | 卖了多少、赚了多少，客户与产品贡献如何 | 销售趋势、客户价值散点图、产品经营矩阵    |
| 库存资金占用与风险分析 | 哪里积压、积压多少钱、库存是否够用 | 月末快照、树状图、风险散点图、安全库存缺口  |
| 订单履约与物流运输分析 | 发货是否准时，哪个仓库或承运商表现较差 | 组合图、承运商成本与准时率、区域地图     |
| 客户投诉与售后闭环分析 | 客户主要投诉什么，责任在哪里，是否及时关闭 | Pareto、责任损失瀑布图、分解树、关闭率 |
